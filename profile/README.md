# Hesaplayıcı

[English](#hesaplayıcı) · [Türkçe](#türkçe)

Hesaplayıcı brings together online calculators, practical guides and reference data in Turkish and English. Use the website to run a calculation, follow the method or check the data behind a result. Developers and AI assistants can access the same calculation tools through the REST API and MCP.

[Website](https://hesaplayici.com/en) · [Calculators](https://hesaplayici.com/en/tools) · [Developer docs](https://hesaplayici.com/en/developers)

## On the website

Use a calculator when you need a result. Follow the worked examples when you want to check the method. Read the guides when the question takes more than a formula to explain.

Calculators show their assumptions and limits. Where a calculation depends on changing data, you can check the source, the relevant dates and earlier values.

[Browse the data →](https://hesaplayici.com/en/data)

## Use the calculations in your application

The calculators are also available through a REST API. The developer docs describe each tool, the inputs it accepts and the results it returns.

Your application uses the same calculation code as the website.

[Read the API docs →](https://hesaplayici.com/en/developers)

## Give your agents calculation superpowers

Connect your AI assistant to Hesaplayıcı through Model Context Protocol (MCP). It can find the available tools, check their inputs and run calculations during a conversation or task.

[Set up MCP →](https://hesaplayici.com/en/developers)

## Türkçe

Hesaplayıcı; çevrim içi hesaplama araçlarını, uygulamalı rehberleri ve başvuru verilerini Türkçe ve İngilizce bir araya getirir. Bir hesap yapmak, yöntemi öğrenmek veya sonucun dayandığı verileri incelemek için web sitesini kullanabilirsiniz. Geliştiriciler ve yapay zekâ asistanları da aynı hesaplama araçlarına REST API ve MCP üzerinden erişebilir.

[Web sitesi](https://hesaplayici.com) · [Hesaplama araçları](https://hesaplayici.com/araclar) · [Geliştirici belgeleri](https://hesaplayici.com/gelistirici)

### Web sitesinde

Bir sonuca ihtiyacınız olduğunda hesaplama araçlarını kullanın. Yöntemi kontrol etmek için örnek hesaplamaları takip edin. Sorunuzun yanıtı bir formülden fazlasını gerektiriyorsa rehberleri okuyun.

Hesaplama araçları, kullandıkları varsayımları ve sınırlarını açıklar. Değişen verilere bağlı hesaplamalarda kaynağı, verinin hangi döneme ait olduğunu ve geçmiş değerleri inceleyebilirsiniz.

[Verileri inceleyin →](https://hesaplayici.com/veri)

### Hesaplamaları uygulamanızda kullanın

Hesaplama araçlarına REST API üzerinden de erişebilirsiniz. Geliştirici belgelerinde her aracın kabul ettiği girdiler ve döndürdüğü sonuçlar açıklanır.

Uygulamanız, web sitesiyle aynı hesaplama kodunu kullanır.

[API belgelerini okuyun →](https://hesaplayici.com/gelistirici)

### Yapay zekâ ajanlarınıza hesaplama gücü katın

Yapay zekâ asistanınızı Model Context Protocol (MCP) üzerinden Hesaplayıcı'ya bağlayın. Asistanınız, bir sohbet veya görev sırasında araçları bulabilir, girdilerini kontrol edebilir ve hesaplama yapabilir.

[MCP bağlantısını kurun →](https://hesaplayici.com/gelistirici)
